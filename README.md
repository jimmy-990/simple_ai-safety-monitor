# AI Safety Monitoring System

This project is a real time AI monitoring system built using YOLOv8 and OpenCV

The idea behind the project is simple  
The camera watches a restricted area and the system checks if a detected object enters that zone  
Once the object enters the area an alert appears immediately on the screen

The project was created to explore how computer vision can be used in smart monitoring and safety systems in a practical way

## What the system does

-Detects objects in real time using a live webcam feed

-Monitors a specific restricted area on the screen

-Triggers an alert when the detected object enters the danger zone

-Displays live detection results with bounding boxes and labels

## Technologies used

-Python

-YOLOv8

-OpenCV

-Ultralytics

## Why this project

I wanted to build something that feels closer to a real system instead of only testing an AI model on images

This project combines AI with monitoring logic and real time processing which makes it more practical and interactive
